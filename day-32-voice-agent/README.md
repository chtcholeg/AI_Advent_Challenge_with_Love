# Day 32 — Голосовой агент

Kotlin Compose Desktop-приложение с полностью офлайн-распознаванием речи. Позволяет управлять чатом с AI голосом: кодовое слово запускает запись, стоп-слова отправляют или отменяют сообщение. При включённом голосовом управлении прослушивание активно постоянно и перезапускается автоматически после каждого цикла.

## Что добавлено по сравнению с предыдущим днём

| Функция | Описание |
|---|---|
| **Vosk STT (офлайн)** | Распознавание речи без интернета на русской модели `vosk-model-small-ru-0.22` |
| **Автозагрузка модели** | Модель скачивается и распаковывается автоматически при первом запуске |
| **Пассивное прослушивание** | Фоновый режим ожидания кодового слова без отправки аудио в облако |
| **Активная запись** | После кодового слова — полноценная запись с отображением текста в реальном времени |
| **Стоп-слова** | «Отправить» — завершить и отправить, «Отмена» — завершить и сбросить |
| **Автозапуск прослушивания** | Включил «Управление голосом» в настройках — микрофон слушает сам, выключать вручную |
| **Автоперезапуск** | После каждого цикла «кодовое слово → запись → стоп» прослушивание возобновляется автоматически |
| **Частичный текст** | Распознанный текст появляется в поле ввода в реальном времени во время записи |
| **JNA-биндинг Vosk** | Кастомный минимальный JNA-интерфейс вместо `org.vosk.*` — обходит краш при загрузке на macOS |

## Как работает голосовое управление

```
Включить в настройках
        ↓
[Пассивное прослушивание] ← автозапуск, автоперезапуск
        ↓ услышал кодовое слово
[Активная запись] — текст виден в поле ввода в реальном времени
        ↓
  ┌─────┴──────┐
«отправить»  «отмена»    (или кнопка Стоп)
     ↓           ↓               ↓
отправить    сбросить     текст остаётся в поле
     └─────────────────────────┘
        ↓
[Пассивное прослушивание] ← автоматически
```

## Кодовые слова (настраиваются)

| Слово | Действие по умолчанию |
|---|---|
| **Слово запуска** | `компьютер` — начать запись |
| **Стоп + отправить** | `отправить` — завершить и отправить сообщение |
| **Стоп + отмена** | `отмена` — завершить и очистить поле |

## Доступные модели

### GigaChat (облако, требует ключ)
- `GigaChat` — базовая
- `GigaChat-Pro` — продвинутая
- `GigaChat-Max` — максимальная

### Ollama (локально, автообнаружение)
Приложение автоматически обнаруживает запущенный Ollama и показывает список доступных моделей. Кнопка «Обновить» — принудительный рефреш.

### Паттерн MVI

`ChatStore` хранит всё состояние голосового пайплайна:

- `isPassiveListening` — ждём кодовое слово
- `isRecording` — идёт активная запись
- `isInitializingSTT` — модель Vosk загружается
- `partialRecognizedText` — текст в реальном времени
- `recognizedText` — финальный результат (при ручной остановке)
- `clearInputTrigger` — инкрементируется при SEND/CANCEL для сброса поля ввода

## Запуск

### Требования

- JDK 17+
- IntelliJ IDEA / Android Studio
- Микрофон

### Настройка

Создайте `local.properties` в корне проекта:

```properties
gigachat.clientId=ваш_client_id
gigachat.clientSecret=ваш_client_secret
```

> Для работы с Ollama ключи не нужны — достаточно запустить `ollama serve` локально.

### Первый запуск с голосом

При первом включении голосового управления приложение автоматически скачает и распакует модель Vosk (~45 МБ) в `~/.config/voice-agent/models/`. После этого инициализация занимает несколько секунд.

### Сборка и запуск

```bash
# Запуск в режиме разработки
./gradlew run

# Сборка дистрибутива
./gradlew packageDmg      # macOS
./gradlew packageMsi      # Windows
./gradlew packageDeb      # Linux
```

## Параметры модели

| Параметр | Диапазон | Описание |
|---|---|---|
| **Temperature** | 0.0 – 2.0 | Случайность ответов |
| **Top P** | 0.0 – 1.0 | Nucleus sampling |
| **Top K** | 1 – 100 | Количество токенов-кандидатов |
| **Max Tokens** | 64 – 8192 | Максимальная длина ответа |
| **Repetition Penalty** | 0.0 – 2.0 | Штраф за повторение токенов |
