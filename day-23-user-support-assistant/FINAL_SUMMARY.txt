🚀 БЫСТРЫЙ СТАРТ

1. БАЗОВОЕ ИСПОЛЬЗОВАНИЕ (без настройки):

   ./gradlew :ai-agent:run
   
   # В AI Agent:
   /support Как запустить AI Agent?

2. С RAG (рекомендуется):

   # Создать индекс FAQ
   export GIGACHAT_CLIENT_ID="..."
   export GIGACHAT_CLIENT_SECRET="..."
   ./gradlew :shared:runIndexing --args="index ./support-docs/faq ./support-knowledge.json md"
   
   # В AI Agent Settings:
   # RAG Mode: ✅ Enabled
   # Index Path: ./support-knowledge.json
   
   /support Проблема с авторизацией

3. С CRM (опционально):

   # Terminal 1: Запустить CRM server
   cd mcp-servers
   python -m crm.main
   
   # Terminal 2: AI Agent
   ./gradlew :ai-agent:run
   
   # Settings → MCP Servers → Add CRM
   
   /support userId=user_001 Проблема с MCP

🏗️ АРХИТЕКТУРА

User: /support [вопрос]
    ↓
CommandHandler.handleSupportCommand()
    ├─ Load: support-docs/config/support-assistant-prompt.md
    └─ Return: NeedsLlmProcessing (enableTools=true)
    ↓
AgentRepository.executeAgent()
    ├─ MCP Tools: get_user, get_ticket, search_tickets
    ├─ RAG Tools: rag_search (FAQ)
    └─ Local Tools: read, grep, bash
    ↓
AI Response
    ├─ Персонализированный (CRM)
    ├─ Точный (RAG)
    ├─ Структурированный (шаги, примеры)
    └─ Эмпатичный (дружелюбный тон)
