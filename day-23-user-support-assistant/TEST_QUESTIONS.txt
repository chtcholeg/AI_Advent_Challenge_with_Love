## How to Use

1. Copy a question from above
2. Paste into AI Agent chat
3. Observe the response
4. Check that:
   - RAG finds relevant info
   - MCP tools are called
   - Response is personalized
   - Answer is helpful

## Expected Behavior

### For FAQ questions:
- Should cite source document (e.g., "support-docs/faq/authentication.md")
- Should provide step-by-step solution
- Should include code examples if relevant

### For MCP questions:
- Should call appropriate MCP tool
- Should show data from CRM
- Should format output nicely

### For combined questions:
- Should use both RAG and MCP
- Should personalize based on user context
- Should mention user's name, plan, tickets
- Should be friendly and helpful

## Quick Test Checklist

After testing, verify:

[ ] RAG finds info in all 5 FAQ documents
[ ] All 7 MCP tools work correctly
[ ] Combined queries use both RAG and MCP
[ ] User context is preserved in conversation
[ ] Error handling works (non-existent IDs)
[ ] Ticket updates persist to JSON file
[ ] Response tone is friendly and professional
[ ] Solutions are clear and actionable
[ ] Code examples are formatted correctly
[ ] Citations include document references

## Performance Expectations

- Simple FAQ: < 3 seconds
- MCP query: < 2 seconds
- Combined (RAG+MCP): < 5 seconds
- No errors or crashes
- Consistent quality across multiple queries
