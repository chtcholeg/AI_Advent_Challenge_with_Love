🚀 Quick Start (2 Steps):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Start Git MCP Server:
   
   cd mcp-servers
   ./START.sh

2. Add to AI Agent:
   
   Settings → MCP Servers → Add Server
   • Name: Git
   • URL: http://localhost:8010/sse
   • API Key: (empty)
   • Enable server

That's it! Test with: "What's the git status?"

  • git_push          - Push to remote

✅ Verification Checklist:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Before testing, verify:

1. Prerequisites:
   □ Python 3.10+ installed (python3 --version)
   □ Git installed (git --version)
   □ In a Git repository (git status)

2. Server Running:
   □ ./START.sh executed successfully
   □ Server shows "Uvicorn running on http://0.0.0.0:8010"
   □ No error messages in console

3. Server Responds:
   □ curl http://localhost:8010/health returns {"status":"healthy"}
   □ All 11 tools listed

4. AI Agent Connected:
   □ Server added in Settings → MCP Servers
   □ Server status shows "Connected" (green)
   □ No errors in AI Agent console

5. Tools Work:
   □ Test command: "What's the git status?"
   □ AI responds with actual git status
   □ Server logs show tool execution

🔧 Troubleshooting:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Server Issues:
  Problem: Server won't start
  Solution: Check Python version, reinstall venv
  Command: cd mcp-servers && rm -rf venv && ./START.sh

Connection Issues:
  Problem: AI Agent shows "Error" status
  Solution: Check server is running, verify URL
  Command: curl http://localhost:8010/health

Repository Issues:
  Problem: "Not a git repository" error
  Solution: Run server from git repo or specify path
  Command: python -m git.main --repo-path /path/to/repo --no-auth

Full troubleshooting: See mcp-servers/CHECKLIST.md
