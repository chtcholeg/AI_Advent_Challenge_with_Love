# Команды AI Agent

## Быстрый старт

В AI Agent теперь доступна система команд! Команды начинаются с `/` и выполняются локально.

## Использование

### Команда `/help`

Показывает информацию о текущем проекте из README.md.

**Пример:**

1. Запустите AI Agent:
   ```bash
   ./gradlew :ai-agent:run
   ```

2. В поле ввода введите:
   ```
   /help
   ```

3. Вы увидите:
   - Описание проекта
   - Список возможностей
   - Последние обновления (Day 21)
   - Команды для быстрого старта
   - Список доступных команд

## Визуальное оформление

Команды отображаются **зеленым цветом** и имеют увеличенный отступ снизу для лучшей читаемости.

## Платформы

- ✅ **Desktop** - полная поддержка, читает README.md из проекта
- ✅ **Android** - поддержка со статическим контентом

## Будущие команды

Планируется добавить:
- `/status` - статус системы
- `/clear` - очистка истории
- `/model` - смена модели
- `/export` - экспорт диалога
- и другие...

---

**Примечание:** Команды обрабатываются локально и не отправляются в AI модель.
