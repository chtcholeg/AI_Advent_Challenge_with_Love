# Day 29 — LLM Parameter Lab: JSON Extractor

Интерактивный инструмент для сравнения влияния параметров LLM на качество структурированного вывода. Берёт неструктурированный текст на входе и пытается извлечь из него JSON — с разными моделями, квантованием, температурой, контекстным окном и системными промптами одновременно.

## Зачем это нужно

JSON-экстрактор — идеальный стенд для демонстрации параметров: результат бинарный (либо валидный JSON, либо нет), что убирает субъективность. Разница между конфигурациями видна без анализа.

## Что можно менять в каждой колонке

| Параметр | Описание | Эффект |
|---|---|---|
| **Модель** | Ollama (локально) или GigaChat (облако) | Качество, скорость, стоимость |
| **Квантование** | q2_K vs q4_K_M vs q8_0 (разные теги одной модели) | Точность vs скорость/память |
| **temperature** | 0.0 – 2.0 | Детерминированность ответа |
| **num_ctx** | 512 – 32768 (только Ollama) | Сколько текста модель "видит" |
| **max_tokens** | Лимит длины ответа | Полнота или обрезанность |
| **System Prompt** | Вкл/выкл + свой текст или пресет | Структура, стиль, схема вывода |

## Доступные модели

### Ollama (локально)
| Модель | Размер | Квантование |
|---|---|---|
| `qwen2.5:0.5b` | 0.4 GB | — |
| `qwen2.5:7b-instruct-q2_K` | 3.0 GB | Q2 (деградированная) |
| `qwen2.5:7b` | 4.7 GB | Q4_K_M (стандарт) |
| `qwen2.5:32b` | 19 GB | Q4_K_M |

### GigaChat (облако, требует ключ)
- `GigaChat` — базовая
- `GigaChat-Pro` — продвинутая
- `GigaChat-Max` — максимальная

> **Примечание:** `num_ctx` — параметр Ollama, для GigaChat недоступен (отображается как N/A).

## Системные промпты (пресеты)

**Детальный (с JSON-схемой)** — жёсткие правила: только JSON, нормализация телефонов и дат, схема полей. Лучший результат на слабых моделях.

**Простой (без схемы)** — одна строка: "Извлеки данные и верни JSON". Показывает насколько модель сама догадывается о структуре.

**Chain-of-Thought** — модель сначала перечисляет что нашла, потом выдаёт JSON. Помогает на сложных текстах, но ломает прямой парсинг JSON.

## Тестовые тексты

- **Запись к мастеру** — имя, телефон, дата, время, услуги, бюджет
- **Объявление о продаже** — товар, характеристики, цена, контакты
- **Отзыв о ресторане** — блюда, сумма, оценка, рекомендация
- **Обращение в поддержку** — имя, email, номер заказа, сумма, телефон

## Запуск

```bash
# 1. Создать .env с ключом GigaChat (опционально)
cat > backend/.env << 'EOF'
GIGACHAT_AUTHORIZATION_KEY=ваш_ключ_из_кабинета_GigaChat
EOF

# 2. Запустить
./start.sh

# Открыть: http://localhost:8002
```

### Ручной запуск

```bash
cd backend
python3.13 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --port 8002 --reload
```

## API

| Метод | URL | Описание |
|---|---|---|
| `GET` | `/api/models` | Список доступных моделей (Ollama + GigaChat если есть ключ) |
| `GET` | `/api/prompts` | Пресеты системных промптов |
| `GET` | `/api/samples` | Тестовые тексты |
| `POST` | `/api/extract` | Одиночная экстракция |
| `POST` | `/api/extract/batch` | Параллельная экстракция нескольких конфигов |

### Тело запроса `/api/extract`

```json
{
  "text": "входной текст",
  "model": "qwen2.5:7b",
  "temperature": 0.1,
  "num_ctx": 4096,
  "max_tokens": 512,
  "system_prompt": "..."
}
```

### Ответ

```json
{
  "raw": "сырой ответ модели",
  "parsed": { "name": "...", "phone": "..." },
  "valid_json": true,
  "parse_error": null,
  "elapsed": 1.23,
  "tokens_generated": 87,
  "tokens_prompt": 142,
  "provider": "ollama"
}
```
