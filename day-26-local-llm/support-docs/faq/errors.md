# Распространенные ошибки

## Ошибки базы данных

### "NoBeanDefFoundException"

**Причина:** Koin DI не инициализирован перед запуском UI.

**Решение:**
1. Убедитесь, что `initKoin()` вызывается в `main()` до UI
2. Проверьте порядок инициализации модулей
3. Перезапустите приложение

### "Database crash after schema change"

**Причина:** Изменена схема БД, но старая база не совместима.

**Решение:**
1. Выполните `./gradlew clean`
2. Удалите базу данных:
   ```bash
   rm -rf ~/.ai-chat/chat.db
   ```
3. Пересоберите проект:
   ```bash
   ./gradlew build
   ```

### "SQLDelight migration error"

**Причина:** Ошибка в SQL миграции или синтаксисе.

**Решение:**
1. Проверьте `.sq` файлы в `sqldelight/`
2. Проверьте синтаксис SQL
3. Пересоздайте схему:
   ```bash
   ./gradlew generateCommonMainChatDatabaseInterface
   ```

## Ошибки API

### "Rate limit exceeded"

**Причина:** Превышен лимит запросов к API.

**Решение:**
1. Подождите несколько минут
2. Проверьте ваш план подписки на GigaChat
3. Используйте другую модель (например, Hugging Face)

### "Model not available"

**Причина:** Выбранная модель недоступна или не поддерживается.

**Решение:**
1. Проверьте доступные модели в настройках
2. Выберите другую модель:
   - GigaChat-Pro
   - GigaChat-Plus
   - Mixtral 8x7B (Hugging Face)
3. Обновите приложение до последней версии

### "Request timeout"

**Причина:** Запрос к API превысил таймаут.

**Решение:**
1. Проверьте интернет-соединение
2. Уменьшите `maxTokens` в настройках
3. Попробуйте другую модель
4. Проверьте статус API: https://status.gigachat.ai

## Ошибки индексирования

### "Indexing credentials error"

**Причина:** Не установлены креденшелы для API.

**Решение:**
1. Установите переменные окружения:
   ```bash
   export GIGACHAT_CLIENT_ID="your_id"
   export GIGACHAT_CLIENT_SECRET="your_secret"
   ```
2. Или проверьте `local.properties`
3. Выполните команду заново:
   ```bash
   ./gradlew :shared:runIndexing --args="index ./docs ./index.json md txt pdf"
   ```

### "Failed to parse PDF"

**Причина:** Ошибка при парсинге PDF файла.

**Решение:**
1. Убедитесь, что PDF не защищен паролем
2. Проверьте, что файл не поврежден
3. Для Desktop: PDFBox требует JDK 17+
4. Попробуйте конвертировать PDF в текст вручную

### "Out of memory during indexing"

**Причина:** Недостаточно памяти для индексирования больших документов.

**Решение:**
1. Увеличьте heap size для JVM:
   ```bash
   export GRADLE_OPTS="-Xmx4g"
   ./gradlew :shared:runIndexing --args="..."
   ```
2. Индексируйте документы по частям
3. Уменьшите размер чанков в настройках

## Ошибки сборки

### "Gradle build failed"

**Общие решения:**
1. Очистите кеш:
   ```bash
   ./gradlew clean
   ```
2. Удалите `.gradle` и пересоберите:
   ```bash
   rm -rf .gradle
   ./gradlew build
   ```
3. Обновите Gradle Wrapper:
   ```bash
   ./gradlew wrapper --gradle-version 8.5
   ```

### "Dependency resolution failed"

**Решение:**
1. Проверьте интернет-соединение
2. Очистите Maven кеш:
   ```bash
   rm -rf ~/.m2/repository
   rm -rf ~/.gradle/caches
   ```
3. Пересоберите проект

### "BuildKonfig secrets not found"

**Причина:** Секреты не скомпилированы в BuildKonfig.

**Решение:**
1. Убедитесь, что `local.properties` существует
2. Проверьте формат файла
3. Выполните:
   ```bash
   ./gradlew clean build
   ```

## Проблемы производительности

### Приложение работает медленно

**Решения:**
1. Уменьшите `maxTokens` в настройках
2. Отключите RAG, если не нужен
3. Используйте более быструю модель
4. Очистите старые сессии и историю

### Долгая загрузка при запуске

**Причины:**
1. Большая база данных сессий
2. Долгая инициализация Koin
3. Долгое подключение к MCP серверам

**Решения:**
1. Архивируйте старые сессии
2. Отключите неиспользуемые MCP серверы
3. Оптимизируйте индекс RAG
