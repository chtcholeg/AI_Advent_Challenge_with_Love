# Day 31 — Персонализация: адаптация AI под пользователя

Kotlin Compose Desktop-приложение с персонализацией AI-ответов. Пользователь заполняет профиль — имя, язык, интересы, уровень детализации — и эти данные автоматически преобразуются в системный промпт, который AI учитывает в каждом ответе.

## Что добавлено по сравнению с предыдущими днями

| Функция | Описание |
|---|---|
| **UserProfile** | Модель профиля: имя, язык, интересы, уровень детализации, использование примеров, свободное описание |
| **ModelParameters** | Настройка температуры, Top P, Top K, Max Tokens, Repetition Penalty через слайдеры |
| **buildSystemPrompt()** | Функция автоматически собирает системный промпт из полей профиля |
| **Предпросмотр промпта** | В настройках отображается итоговый системный промпт в реальном времени |
| **Expandable-секции** | Настройки модели и профиля пользователя сворачиваются/разворачиваются |
| **Hint-заполнение** | В полях профиля нажатие → вставляет текст-подсказку |

## Параметры профиля пользователя

| Поле | Описание | Пример |
|---|---|---|
| **Имя** | AI обращается к пользователю по имени | `Олег` |
| **Предпочитаемый язык** | Язык ответов | `Русский` |
| **Области интересов** | Темы, которые интересны пользователю | `Программирование, AI, наука` |
| **Уровень детализации** | Краткий / Средний / Подробный | Chip-переключатель |
| **Использовать примеры** | Включать/выключать практические примеры | Toggle |
| **Дополнительное описание** | Опыт, предпочтения, особые пожелания | Свободный текст |

## Параметры модели

| Параметр | Диапазон | Описание |
|---|---|---|
| **temperature** | 0.0 – 2.0 | Случайность ответов |
| **Top P** | 0.0 – 1.0 | Nucleus sampling |
| **Top K** | 1 – 100 | Количество токенов-кандидатов |
| **Max Tokens** | 64 – 8192 | Максимальная длина ответа |
| **Repetition Penalty** | 0.0 – 2.0 | Штраф за повторение токенов |

## Доступные модели

### GigaChat (облако, требует ключ)
- `GigaChat` — базовая
- `GigaChat-Pro` — продвинутая
- `GigaChat-Max` — максимальная

### Ollama (локально, автообнаружение)
Приложение автоматически обнаруживает запущенный Ollama и показывает список доступных моделей. Кнопка «Обновить» — принудительный рефреш.

## Запуск

### Требования

- JDK 17+
- IntelliJ IDEA / Android Studio

### Настройка

Создайте `local.properties` в корне проекта:

```properties
gigachat.clientId=ваш_client_id
gigachat.clientSecret=ваш_client_secret
```

### Сборка и запуск

```bash
# Desktop
./gradlew run

# Сборка дистрибутива
./gradlew packageDmg      # macOS
./gradlew packageMsi      # Windows
./gradlew packageDeb      # Linux
```

## Как работает персонализация

1. Пользователь открывает настройки и заполняет **Профиль пользователя**
2. Функция `UserProfile.buildSystemPrompt()` собирает системный промпт из заполненных полей
3. При каждом запросе к AI `ChatRepository` подставляет этот промпт в поле `system`
4. AI учитывает имя, язык, интересы и стиль ответов во всём диалоге

Пример сгенерированного системного промпта:
```
Обращайся к пользователю по имени: Олег. Отвечай на языке: Русский.
Области интересов пользователя: Программирование, AI. Уровень детализации ответов: Подробный.
Используй практические примеры в ответах.
```
