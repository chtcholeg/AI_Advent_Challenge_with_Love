## 🐛 TROUBLESHOOTING

### Проблема 1: "Команда /review-pr 5 не работает"

**Симптом:** Ошибка "Unknown command" или ничего не происходит

**Решение:**
1. Проверить, что AI Agent действительно запущен:
   ```bash
   ps aux | grep "ai-agent" | grep -v grep
   ```

2. Проверить логи:
   ```bash
   tail -50 /tmp/ai-agent.log
   ```

3. Перезапустить:
   ```bash
   pkill -f "gradle.*ai-agent"
   ./gradlew :ai-agent:run
   ```

### Проблема 2: "Review занимает слишком долго"

**Симптом:** Ждём больше 2 минут

**Причины:**
- MCP сервер не отвечает
- Сетевые проблемы с GigaChat API
- Большой размер промпта

**Решение:**
1. Проверить MCP сервер:
   ```bash
   curl http://localhost:8010/health
   ```

2. Проверить логи AI Agent на ошибки:
   ```bash
   tail -100 /tmp/ai-agent.log | grep -i error
   ```

3. Если ничего не помогает - перезапустить MCP сервер:
   ```bash
   cd mcp-servers && ./START.sh
   ```

### Проблема 3: "Секция технологий отсутствует"

**Симптом:** В ответе нет секции "📋 ОБНАРУЖЕННЫЕ ТЕХНОЛОГИИ"

**Причины:**
1. Изменения не скомпилированы
2. Старая версия AI Agent в памяти
3. Ошибка в коде

**Решение:**
1. Проверить компиляцию:
   ```bash
   ./gradlew :ai-agent:compileKotlinDesktop
   ```

2. ПОЛНОСТЬЮ перезапустить AI Agent:
   ```bash
   pkill -f "gradle.*ai-agent"
   sleep 2
   ./gradlew :ai-agent:run
   ```

3. Проверить, что файл SpecializedChecklists.kt на месте:
   ```bash
   ls -la ai-agent/src/commonMain/kotlin/ru/chtcholeg/agent/domain/service/SpecializedChecklists.kt
   ```
