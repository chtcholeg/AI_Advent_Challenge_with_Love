# Использование функций

## Режимы ответов

Приложение поддерживает несколько режимов ответов AI:

### Normal (Обычный)
Стандартный режим диалога с AI.

### JSON Mode
AI отвечает в формате JSON. Используйте для:
- Структурированных данных
- API ответов
- Парсинга результатов

**Пример:**
```
Вопрос: "Верни список задач в JSON"
Ответ: {"tasks": ["task1", "task2", "task3"]}
```

### XML Mode
AI отвечает в формате XML. Подходит для:
- Интеграции с legacy системами
- Генерации конфигураций
- Структурированных документов

### Dialog Mode (Диалог)
AI выступает в роли собеседника, задает уточняющие вопросы.

### Step-by-Step (Пошаговый)
AI разбивает решение на шаги и объясняет каждый.

### Expert Panel (Панель экспертов)
AI использует несколько "экспертных" точек зрения для ответа.

## RAG (Retrieval-Augmented Generation)

### Что такое RAG?

RAG позволяет AI отвечать на вопросы, используя вашу документацию и базу знаний.

### Как использовать RAG?

1. **Индексируйте документы:**
   ```bash
   ./gradlew :shared:runIndexing --args="index ./docs ./index.json md txt pdf"
   ```

2. **Запустите AI Agent:**
   ```bash
   ./gradlew :ai-agent:run
   ```

3. **Включите RAG mode в настройках**

4. **Задавайте вопросы:**
   ```
   "Как настроить MCP сервер?"
   ```
   AI найдет информацию в проиндексированных документах.

### Проблемы с RAG

#### "No relevant context found"

**Решение:**
1. Убедитесь, что документы проиндексированы
2. Проверьте путь к индексу в настройках
3. Переиндексируйте документы:
   ```bash
   ./gradlew :shared:runIndexing --args="index ./docs ./index.json md txt pdf"
   ```

#### "Embedding service error"

**Решение:**
1. **Для GigaChat эмбеддингов:** проверьте креденшелы
2. **Для Ollama:** убедитесь, что Ollama запущен:
   ```bash
   ollama serve
   ```

## Сессии и история

### Как сохранить сессию?

Сессии сохраняются автоматически в локальной БД SQLDelight.

### Как восстановить сессию?

1. Откройте список сессий (Sessions)
2. Выберите нужную сессию
3. Продолжите диалог

### Как очистить историю?

1. В списке сессий нажмите на сессию
2. Выберите "Delete" или "Clear"

## Напоминания (Reminders)

### Как создать напоминание?

Используйте команду в чате:
```
Напомни мне через 1 час проверить почту
```

AI создаст напоминание через Local Tool.

### Проблемы с напоминаниями

#### "Failed to create reminder"

**Решение:**
1. Проверьте формат времени
2. Убедитесь, что Local Tools включены в настройках
3. Проверьте права приложения на уведомления

## Интеграция с Telegram

Приложение поддерживает отправку напоминаний в Telegram.

### Настройка:

1. Получите Telegram Bot Token от @BotFather
2. Добавьте в настройки приложения
3. Укажите ваш Telegram Chat ID

## Экспорт диалогов

### Как экспортировать диалог?

1. Откройте нужную сессию
2. Нажмите "Export"
3. Выберите формат (TXT, JSON, Markdown)
4. Сохраните файл
