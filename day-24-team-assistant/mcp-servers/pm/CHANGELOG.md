# Changelog

Все значимые изменения в PM MCP Server.

## [1.1.0] - 2026-02-16

### Добавлено

- **Сквозная нумерация задач** с хранением счётчика в метаданных
  - Новый формат файла tasks.json с секцией metadata
  - Функция `load_metadata()` для загрузки метаданных
  - Функция `save_metadata()` для сохранения метаданных
  - Обновлённая `generate_task_id()` с использованием сквозного счётчика

- **Скрипт миграции** `migrate_tasks.py`
  - Автоматическая конвертация старого формата в новый
  - Создание резервной копии перед миграцией
  - Определение last_task_id на основе существующих задач

- **Документация**
  - `SEQUENTIAL_ID_UPDATE.md` - подробная документация об изменениях
  - `QUICKSTART_UPDATES.md` - краткая инструкция по использованию
  - `CHANGELOG.md` - журнал изменений

### Изменено

- **load_tasks()** - добавлена поддержка обоих форматов (старого и нового)
- **save_tasks()** - теперь всегда сохраняет в новом формате с метаданными
- **generate_task_id()** - использует сквозной счётчик вместо len(tasks) + 1
- Обновлён README.md с информацией о новом формате

### Улучшено

- Гарантированная уникальность ID задач
- Обратная совместимость со старым форматом
- Более надёжная генерация ID без перебора существующих

### Документировано

- Расширено описание `update_task` в README
- Добавлены примеры изменения статуса и приоритета
- Добавлены ссылки на новую документацию

## [1.0.0] - 2026-02-15

### Добавлено

- Базовый PM MCP Server
- Управление задачами (CRUD)
- Фильтрация по статусу, приоритету, исполнителю
- Dashboard с метриками
- AI-анализ приоритетов (GigaChat)
- Git integration (branch, commits)
- Интеграция с AI Agent через команду /task

### Возможности

- Создание задач (`create_task`)
- Просмотр задач (`list_tasks`, `get_task`)
- Обновление задач (`update_task`) - включая изменение статуса
- Удаление задач (`delete_task`)
- Dashboard (`get_project_dashboard`)
- Team workload (`get_team_workload`)
- AI priority analysis (`analyze_priorities`)
- AI priority suggestion (`suggest_priority`)

### Статусы

- open, in_progress, review, done, blocked, cancelled

### Приоритеты

- low, medium, high, critical

## Формат версий

[MAJOR.MINOR.PATCH]

- **MAJOR** - несовместимые изменения API
- **MINOR** - новые возможности (обратно совместимые)
- **PATCH** - исправления багов

## Типы изменений

- **Добавлено** - новые функции
- **Изменено** - изменения в существующей функциональности
- **Устарело** - функции, которые будут удалены
- **Удалено** - удалённые функции
- **Исправлено** - исправления багов
- **Безопасность** - исправления уязвимостей
